Date: 2026-09-11

## D006 Canonicalization

Status: ACCEPTED FOR TRUST CORE V0.4
Date: 2026-09-11

Scheme ID: FPP_JCS_1

Use RFC 8785 JCS over the restricted project JSON data model. Consequential scientific decimals use canonical decimal strings. JSON floating point values are prohibited in normative scientific objects.

## D007 Dependency identity

Status: ACCEPTED FOR TRUST CORE V0.4
Date: 2026-09-11

Every consequential dependency binds both semantic object ID and full SHA256 content hash.

Event identity uses a noncircular two stage payload and final content hash construction.

## D008 Explicit trust root

Status: ACCEPTED FOR TRUST CORE V0.4
Date: 2026-09-11

Validators receive trusted manifest and governance acceptance inputs externally. Candidate objects and their dependency graph cannot select or regenerate the trust root used to validate themselves.

## D009 Immutable lifecycle evidence

Status: ACCEPTED FOR TRUST CORE V0.4
Date: 2026-09-11

Forecasts, corrections, review decisions, governance decisions, and anchor evidence are immutable records. Lifecycle and prospective status are derived validator outputs rather than mutable fields in issued forecast objects.

## D010 Deterministic cycle completeness

Status: ACCEPTED FOR TRUST CORE V0.4
Date: 2026-09-11

Confirmatory cycle slots are generated by a versioned IssuanceSchedulePolicy bound by the historical trusted manifest. A cycle plan must be externally committed before its fixed execution window and must account for every required slot.

## D011 Execution selection control

Status: ACCEPTED FOR TRUST CORE V0.4
Date: 2026-09-11

Confirmatory methods must use deterministic replay, postcommit public randomness, or independently auditable complete request accounting. Uncontrolled nondeterminism is ineligible for confirmatory prospective trust claims.

## D012 Genesis bootstrap governance boundary

Status: ACCEPTED AS INTERFACE, INSTANCE DEFERRED TO GENESIS
Date: 2026-09-11

The first manifest is accepted against a BootstrapGovernanceRoot supplied outside the candidate manifest graph. FTC_001 freezes its contract. Genesis must instantiate the exact authority key, rule bytes, and external proof before prospective operation.

## D013 FTC_001 design freeze

Status: ACCEPTED
Date: 2026-09-11

Forecast Trust Core normative design version 0.4 is frozen for synthetic implementation after three adversarial design review passes and remediation.

This decision authorizes synthetic implementation only. It does not authorize Forecast Ledger creation, genuine prospective forecasting, or Genesis acceptance.
