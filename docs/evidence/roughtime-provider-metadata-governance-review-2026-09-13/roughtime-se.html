roughtime.se

This domain hosts a stratum 1 Roughtime time synchronization server implementing Roughtime draft-19.

Hosting is provided by STUPI AB and the server is directly connected to atomic clocks that track the UTC timescale. Feel free to use this server as needed to perform time synchronization, timestamping, and to test and develop software for the Roughtime protocol.

To facilitate testing and troubleshooting, this server also runs an NTS-enabled NTP server on port 123.
