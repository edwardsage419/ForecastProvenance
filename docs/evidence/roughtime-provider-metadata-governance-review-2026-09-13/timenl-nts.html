TimeNL — Network Time Security (NTS)

Our NTS-enabled unicast server pool (ntspool.time.nl) consists of four stratum 1 servers:

Name Primary reference clock Secondary reference clock Remark
ntppool1.time.nl Galileo+GPS DCF77+Rubidium holdover
ntppool2.time.nl Galileo+GPS DCF77+Rubidium holdover
ntppool3.time.nl Atomic clocks: UTC(VSL) Rubidium holdover pre-production
ntppool4.time.nl Atomic clocks: UTC(VSL) Rubidium holdover pre-production

Using our servers

For production, use ntppool1.time.nl and ntppool2.time.nl.

You may want to add ntppool3.time.nl and ntppool4.time.nl for time derived from the UTC(VSL) atomic clocks.

Combined they can be configured with the 'pool' directive as ntspool.time.nl.

Or use any.time.nl for our BGP anycasted NTS stratum 2 server.

The original pilot server nts1.time.nl is still available for experiments.

⚠  It's not recommended to use that server in a production environment!

Experimental servers

The experimental NTS server (nts1.time.nl) currently runs Chrony 4.8-2ubuntu1 in a special configuration that is NOT SUITABLE for serious use.

On another NTS server, ntpd-rs.sidnlabs.nl, we currently run an experiment with Version 1.8.0-1, an NTP/NTS server written in Rust, able to take part in an NTS pool (yes, NTS, not NTP). The one we run also has NTPv5 enabled - more specifically, with 'draft-ietf-ntp-ntpv5-08' in the Draft Identification Extension Field.

Roughtime

We also run an experiment with roughtime, currently with these settings:

{
  "servers": [
    {
      "name": "TimeNL-Roughtime",
      "version": "1",
      "publicKeyType": "ed25519",
      "publicKey": "v2CievhgKsxzlWPwIkYFUXeA51Akhkv5uhJCj1/kbiY=",
      "addresses": [
        {
          "protocol": "udp",
          "address": "rough.time.nl:2002"
        }
      ]
    }
  ]
}

This server implements 'draft-ietf-ntp-roughtime-12' from https://github.com/tannerryan/roughtime v1.14.0.

Please note that when you use older versions of the client from https://github.com/int08h/roughenough/, there may be a compatibility issue with the server we provide. This has meanwhile been fixed.

Please use this experimental service at your own risk, and make sure to add at least two other servers to your server list for redundancy.

SRV records

We also run experiments with SRV records for an NTS Pool. Please note that you require adapted client software to make use of them.

TimeNL: ntspool.time.nl

You can check which geolocation is determined for you with: dig +short TXT whoami.srv.ntspool.nl
